# Day 07 – Linux File System Hierarchy & Scenario-Based Practice

## Task

### Part 1: Linux File System Hierarchy (30 minutes)

**Core Directories:**
## 1 `/` (root Directory)
* The root directory is the starting point of the Linux file system.
All files and directories exist under `/`
* Used this when navigating the overall Linux file system structure.
* There are home, root, ect.. folders

## 2 `/home` (home directories)
* Contains home directories for normal users.
* Each user gets a personal workspace here.
* every ubuntu has default user called ubuntu
* There is ubuntu folder

## 3 `/root` (Root user's home directory)
* Home directory of the root user (administrator).
* Used this when performing administrative tasks as root.
* There are .bashrc and .profile

## 4 `/etc` (Configuration files)
* Stores system-wide configuration files.
* Used this when changing system or service configurations.
* There are alternatives, cron.daily, environment, gshadow, etc..

## 5 `/var/log` (Log files)
* Contains system and application log files.
* Used this when troubleshooting system or service issues.
* There are alternatives.log, apt, bootstrap.log, btmp, dpkg.log, faillog, lastlog, wtmp, etc

## 6 `/tmp` (Temporary files)
* Stores temporary files created by applications and users.
* Used this when checking temporary application data.

**Additional Directories:**
## 1 `/bin` (Essential command binaries)
* Contains essential Linux command binaries.
* Used this when running basic Linux commands.
* There are cksum, dpkg, gpasswd, linux32, mountpoint, etc

## 2 `/usr/bin` (User command binaries)
* Contains user command binaries and installed programs.
* Used this when checking installed software commands.
* There are cksum, dpkg, gpasswd, linux32, mountpoint, etc

## 3 `/opt` (Optional/third-party applications)
* Used for optional or third-party applications.
* Used this when managing third-party software installations.
